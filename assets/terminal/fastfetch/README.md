# Shared FastFetch identity

`logo.txt` is generated by `scripts/generate-assets.py` from the locked R5
symbol and must not be hand-edited. Its `$1` and `$2` placeholders map to the
canonical blue and orange in `config.jsonc`. The compact Unicode block-art
format works without a terminal image protocol; FastFetch falls back to its
auto-detected built-in logo if the file cannot be read.

`config.jsonc` is the distribution-neutral shared configuration. Packages
install it beside the logo under `/usr/share/oblinux/terminal/fastfetch/`.
FastFetch does not document `/etc/xdg/fastfetch/config.jsonc` as an automatic
system default, so downstreams explicitly invoke this file or non-destructively
seed a user config. A user's `~/.config/fastfetch/config.jsonc` remains under
user control. Downstreams may replace the module list, but must reference this
packaged logo rather than copying or recreating it.
