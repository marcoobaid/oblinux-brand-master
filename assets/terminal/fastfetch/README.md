# Shared FastFetch identity

`logo.txt` is generated by `scripts/generate-assets.py` from the locked R5
symbol and must not be hand-edited. Its `$1` and `$2` placeholders map to the
canonical blue and orange through ANSI truecolor sequences in `config.jsonc`,
including FastFetch 2.40.4. Hex color strings are intentionally avoided because
FastFetch added them in 2.42.0.

The selected 30-column by 15-row representation uses common Unicode 2×2
quadrant block elements and therefore samples the locked symbol at an effective
60×30 grid. Candidates at 28×14 and 32×16 were also evaluated. The 30×15 result
was the smallest candidate that materially preserved the R5 curves, orange
internal form, and negative spaces without dominating the system-information
modules. It requires UTF-8 and ordinary Block Elements coverage, but no Nerd
Font, custom font, terminal image protocol, or graphics helper. FastFetch falls
back to its auto-detected built-in logo if the file cannot be read.

`config.jsonc` is the distribution-neutral shared configuration. Packages
install it beside the logo under `/usr/share/oblinux/terminal/fastfetch/`.
FastFetch does not document `/etc/xdg/fastfetch/config.jsonc` as an automatic
system default, so downstreams explicitly invoke this file or non-destructively
seed a user config. A user's `~/.config/fastfetch/config.jsonc` remains under
user control. Downstreams may replace the module list, but must reference this
packaged logo rather than copying or recreating it.
