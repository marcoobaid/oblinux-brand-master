# Locked R5 reference

The project owner supplied the “OBLinux – R5 Locked Design” visual identity board
on 2026-08-23. It defines the symbol, `OBLinux` wordmark, lockups, monochrome
variants, clear space, small-size behavior, colors, and sample system applications.

The authoritative guide is preserved as `oblinux-r5-visual-identity-guide.jpg`.
SHA-256: `72159cc6085729092fdc27d40b82ad28753042a7a51b122112244bc42aee4443`.
It is a design reference, not a generated deliverable or package payload.

The corrected master geometry and outlined wordmark were measured from the large
primary artwork on this guide. Refinements must be compared to it and may not
change the identity.
