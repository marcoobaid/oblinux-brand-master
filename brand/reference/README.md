# Locked R5 reference

The project owner supplied the “OBLinux – R5 Locked Design” visual identity board
on 2026-08-23. It defines the symbol, `OBLinux` wordmark, lockups, monochrome
variants, clear space, small-size behavior, colors, and sample system applications.

The original attachment remains outside the repository pending an explicit
redistribution/provenance decision. This records the reference without silently
copying an unknown-license raster into release packages.

The master SVGs preserve the interlocking circular O/B construction, open right
edge, blue outer form, orange upper/right B stroke, and continuous wordmark.
Refinements must be compared to the locked board and may not change the identity.
